    01Back-end · Orman Association · 2026

    OrmanSystem API

    A humanitarian aid management system for Orman Association. I built the repository layer on Entity Framework Core and a RESTful ASP.NET Core Web API on top of it, with DTOs, AutoMapper and consistent routing.

    • ASP.NET Core
    • EF Core
    • AutoMapper
    • SQL Server

    02Desktop · Orman Association · 2026

    OrmanDesktop

    A Windows Forms client for the association's staff. It talks to the API through dedicated service and DTO layers, so daily data entry stays fast and dependable.

    • C#
    • Windows Forms
    • HttpClient
