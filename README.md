# Mohamed Rafat — Portfolio

Personal portfolio of **Mohamed Rafat**, a full-stack web developer (React + ASP.NET Core) from Assiut, Egypt.

Built by hand with plain **HTML, CSS and JavaScript**, with no frameworks or libraries:
- Split-letter headline animation and an animated photo pill
- Infinite skills marquee and a spinning SVG text badge
- Bento grid with a count-up GPA
- Sticky stacked project cards with mockups drawn in CSS
- Custom blend-mode cursor, magnetic button and scroll progress bar
- Fully responsive, and respects `prefers-reduced-motion`
